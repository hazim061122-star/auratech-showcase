# AuraTech Showcase

Build a premium, portfolio-grade e-commerce website for a tech gadgets & accessories brand (wireless earbuds, smartwatches, portable speakers, chargers, etc). This is meant to stand out as a highly interactive, modern showcase — not a generic template store.

Branding: no fixed brand identity yet — invent a clean, modern brand name, logo wordmark, and color palette suited to tech/gadgets (dark mode friendly, with a vibrant accent color like electric blue, purple, or neon green). Keep it premium and minimal, not cartoonish.

Core pages:
1. Homepage — bold hero section, featured products grid, brand story/USP section, testimonials, newsletter signup.
2. Product listing page — filter/sort by category, price, rating; grid layout with hover interactions.
3. Product detail page — image gallery, 360°/rotate-style product viewer (simulate with a draggable image sequence or CSS 3D transform if a real 3D model isn't available), specs tabs, related products, add-to-cart.
4. Cart & checkout flow (front-end only, no real payment integration needed — mock it).
5. About/portfolio-style footer.

Interactivity requirements (this is the priority — make it feel alive):
- Smooth scroll-triggered animations (fade/slide/reveal on scroll)
- Rich hover effects on product cards (image swap, tilt/parallax, quick-view overlay)
- A 3D or pseudo-3D interactive product viewer on the product detail page (drag to rotate)
- Micro-interactions on buttons, cart icon, filters
- Smooth page transitions

Use placeholder/stock-style product images for now (no real product photography yet — I'll swap in AI-generated visuals later). Make sure the layout, spacing, and typography feel professional and distinctive — avoid generic Bootstrap/SaaS-template look.
